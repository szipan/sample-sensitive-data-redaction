# AgentCore Redaction Agent runtime dependencies (task 18.2).
# - bedrock-agentcore: Amazon Bedrock AgentCore Runtime SDK, imported as
#   `bedrock_agentcore`; provides `BedrockAgentCoreApp`, which wires the
#   Runtime entrypoint that AgentCore invokes.
# - strands-agents: Strands Agents SDK, imported as `strands`. It now has an
#   in-repo caller: `agent/redaction_agent.py` assembles the redaction agent's
#   full tool set with `strands.Agent` + `strands.tool`, wrapping each plain
#   pipeline tool via `tool(fn)` at assembly time and registering them on an
#   `Agent(tools=[...])`. The tool modules stay strands-free; the SDK coupling
#   lives only in `redaction_agent.py`. The deterministic fixed-order pipeline
#   (`agent/orchestration.py handle_job`) still drives execution -- the
#   Agent's reasoning loop is intentionally not run -- so the pin stays
#   deliberate and forward-looking for future model-driven agent work. Do not
#   drop it as an unused dependency.
# Neither SDK is needed to run the backend unit tests. `agent/runtime.py`
# imports neither SDK at all -- it stays SDK-independent. The SDK imports live
# only on the tracked entrypoint `agent/main.py`: it imports `bedrock_agentcore`
# at module level (for `BedrockAgentCoreApp`) and pulls `strands` lazily inside
# `invoke` (via `agent/redaction_agent.py`), so no unit-tested path loads either
# SDK. Both are now installed in backend/.venv so the pins are import-verified
# rather than merely wheel-verified.
#
# Both are pinned so the Runtime image is reproducible; the pins are the
# latest versions published on PyPI at the time of pinning. Verified in
# backend/.venv (CPython 3.13, Windows) at these exact pins: `import strands`
# and `import bedrock_agentcore` both succeed, and each API below resolves --
# `Agent(tools=[...])` was constructed from a `@tool`-decorated function, and
# `BedrockAgentCoreApp()` was instantiated with `app.entrypoint` applied as a
# decorator and `app.run` present as a callable. The full 258-test backend
# suite passes unchanged with both installed. Runtime uses only these APIs,
# which must be re-checked if either pin is bumped:
#   strands: `from strands import Agent, tool`, `tool(fn)` wrapping of plain
#       functions, `Agent(tools=[...])`, `agent.tool_names`
#   bedrock_agentcore: `from bedrock_agentcore.runtime import
#       BedrockAgentCoreApp`, `app.entrypoint`, `app.run()`
strands-agents==1.50.2
bedrock-agentcore==1.20.0
